### Selected work

**OKD — Meta**
Production OKD (OpenShift/Kubernetes) cluster built from scratch for a network of
public hospitals (ESEs), in partnership with the Government of Meta (Colombia):
3 masters + 4 workers on VMs, a bastion with DNS/DHCP/HAProxy, MongoDB and
PostgreSQL clusters, full observability (Prometheus, Grafana, ELK, Zipkin), and
an alternate center in Medellín. Runs 26 Spring Boot microservices and an Angular
front — private network, VPN-only access.
`OKD · Kubernetes · Linux · HAProxy · MongoDB · PostgreSQL · Spring Boot · Angular`

**Expediente Municipal — Caldas**
Platform for tracking the Territorial Planning Plan (POT) of the municipalities
of Caldas, built under an agreement between UTP and the Government of Caldas.
Documentation, indicators and cartography in one place — in active use, running
on a private institutional network.
`Angular · Spring Boot · PostgreSQL · MongoDB`

**RISC-V Simulator** · [repo](https://github.com/amirhurtado/RiscVSiriusStudio)
Interactive RISC-V assembly simulator delivered as a VS Code extension, built
within the Sirius UTP research group to support the Computer Architecture
course. In use at UTP.
`TypeScript · React · VS Code API`

**Portfolio**
Personal site with a real-time WebGL scene, custom reactivity layer and a
bilingual experience.
`React · three.js · GLSL · GSAP`
